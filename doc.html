📱 Projeto de Automação Mobile - WebdriverIO

Suíte de testes E2E robusta utilizando WebdriverIO, Appium, Mocha e Chai.

🛠️ Ferramentas e Downloads

  • Android Studio: Baixar aqui
  • Appium Inspector: Baixar aqui

⚙️ Configuração do Ambiente Local

Android Studio

Utilizado para gerenciar o SDK e emuladores. Configure a variável ANDROID_HOME e adicione as pastas platform-tools e emulator ao seu PATH do sistema. No Device Manager, crie um emulador (ex: Pixel 6) com aceleração de hardware.

Appium Inspector

Ferramenta visual para mapeamento de elementos. Conecte utilizando as Remote Capabilities (platformName, deviceName, etc) conforme seu wdio.conf.js. Priorize o uso de accessibility ID para seletores mais estáveis.

🚀 Como Executar Localmente

Certifique-se de que o Appium Server está rodando e o emulador/simulador aberto.

# 1. Instalar dependências
npm install

# 2. Executar Android
npm run test:android

# 3. Executar iOS
npm run test:ios

📊 Relatórios e CI/CD

Os testes são executados automaticamente via GitHub Actions. Para gerar e visualizar o relatório Allure localmente:

npx allure generate allure-results --clean -o allure-report
npx allure open allure-report
